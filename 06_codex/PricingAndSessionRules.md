# 文档修改定价与会话规则

更新时间：2026-05-02

## 推荐上线口径

默认主套餐建议定为 `¥19.9 / 文档`。

这个价格不是按 DeepSeek token 成本加成，而是按用户价值、失败重试、格式复核、下载交付和客服预期定价。DeepSeek V4 的 cache hit 成本很低，但缓存是 best-effort，不应把“缓存一定命中”写进用户承诺。

## 上传后的时间规则

- 免费上传后：给 `10 分钟` 预览期，可看文档结构、页数、表格/批注数量、预计复杂度和报价。
- 付款后：给 `2 小时` 活跃修改窗口，适合利用 DeepSeek 缓存做同一文档连续追改。
- 下载保留：最终文件保留 `24 小时` 下载窗口。
- 超过 2 小时继续修改：允许继续打开项目，但按“新一轮修改”计费或消耗追加次数。
- 超过 24 小时：为隐私和成本，默认清理文件，用户需要重新上传。

## 自动报价因子

上传 inspect 后，用下面因素给出价格提示：

- 页数或幻灯片数量。
- 文本 token 估算量。
- 表格数量。
- 批注数量。
- 是否有参考材料、模板或 PDF。
- 是否需要“全篇格式统一”“逐条批注处理”“合同/论文级严谨修订”。
- 是否需要多轮连续追改。

## MVP 默认公式

先用固定套餐，不急着做复杂动态定价。动态报价可以作为第二阶段。

第一阶段：

- 默认推荐 `标准修改 ¥19.9`。
- 如果文档小于等于 20 页，显示 `快速修改 ¥9.9`。
- 如果文档大于 60 页、表格超过 20 个、批注超过 30 条，显示 `深度修改 ¥39.9` 或 `上传后报价`。
- 每个套餐都显示“包含几轮指令”和“有效修改时间”，避免用户以为一次付款可以无限期无限轮修改。

第二阶段：

```text
报价 = 基础价 + 规模价 + 复杂度价

基础价：
  快速修改 ¥9.9
  标准修改 ¥19.9
  深度修改 ¥39.9

规模价：
  超过套餐页数后，每 20 页 +¥5

复杂度价：
  表格超过 20 个 +¥10
  批注超过 30 条 +¥10
  参考材料超过 3 个 +¥10
  论文/合同严谨模式 +¥20
```

## 页面必须展示的信息

上传后，页面左侧或右侧顶部应该显示：

- 当前文档属于哪个套餐。
- 修改窗口倒计时。
- 剩余指令轮数。
- 下载保留倒计时。
- 超出后如何续费。
- 明确说明“缓存命中可降低成本，但不作为用户权益保证”。

## DeepSeek V4 成本口径

- DeepSeek API Context Caching 默认开启，不需要为命中特性额外改代码。
- 官方说明命中要求后续请求完整匹配已经持久化的 cache prefix unit。
- 官方说明缓存是 best-effort，不保证 100% 命中；缓存不再使用后通常会在几小时到几天内自动清理。
- 响应 usage 会返回 `prompt_cache_hit_tokens` 和 `prompt_cache_miss_tokens`，前端可据此展示命中率。
- 2026-05-02 官方价格页显示 `deepseek-v4-flash` 和 `deepseek-v4-pro` 都区分 cache hit / cache miss 输入价格：`deepseek-v4-flash` 为 `$0.0028 / 1M cache hit input`、`$0.14 / 1M cache miss input`、`$0.28 / 1M output`；`deepseek-v4-pro` 当前折扣价为 `$0.003625 / 1M cache hit input`、`$0.435 / 1M cache miss input`、`$0.87 / 1M output`。

## 当前建议

MVP 不要按 token 对用户报价。用户不理解 token，也不应该承担缓存波动。

建议用户看到的是：

- `¥9.9`：小文档快速改。
- `¥19.9`：默认主力套餐。
- `¥39.9`：长文档、论文、批注多、格式复杂。
- `¥69 起`：超长/高风险文档人工或半人工报价。

## 已接入网页的第一阶段

- 上传文档后，右侧输入区上方显示报价卡。
- 报价卡会显示套餐名称、价格、修改窗口、剩余轮次、下载保留时间和 10 分钟报价倒计时。
- 报价逻辑会参考文档类型、估算页数、表格数量、批注数量、参考材料数量和文件大小。
- 修改完成后，下载按钮默认显示为 `解锁下载`，不再直接暴露文件下载。
- 后端 `/api/session/:id/download` 已加支付锁：`CHECKOUT_REQUIRED=1` 时，未支付 session 会返回 HTTP `402`。
- 付款使用 Stripe Checkout Session；支付成功后由 `/api/checkout/confirm` 或 Stripe webhook 把当前文档 session 标记为已支付。
- 左侧修改稿预览不再读取下载 URL，而是走 `/api/session/:id/inspect`，避免未付款时通过预览刷新拿到二进制文件。
- 当前仍未接入真实权益扣减、后端 2 小时修改窗口强制过期和 24 小时文件保留任务；这些属于上线前第二阶段。
